The Black Friday Edit

Price checks: 25, 27 & 30 Nov

Connect this device

To save changes, the app needs a GitHub key that can only edit your black_friday repo. You only do this once. The key stays on this device and isn't saved to the site.

  1. Open GitHub's new token page (signed in as ellalwoods).
  2. Name it "BF Edit". Set Expiration to No expiration.
  3. Under Repository access choose Only select repositories and pick black_friday.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Press Generate token, copy it and paste it below.
